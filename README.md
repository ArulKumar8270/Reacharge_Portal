# Nexus - E-commerce + Wallet + Recharge + Utility Bill Payments

A comprehensive mobile application with admin dashboard for e-commerce, wallet, recharge services, and utility bill payments.

## Project Structure

```
Nexus/
├── mobile-app/          # Flutter mobile application (Android + iOS)
├── admin-dashboard/     # React admin dashboard
├── backend/             # Node.js backend API
└── docs/                # Documentation and phase plans
```

## Technology Stack

- **Mobile App**: Flutter (Android + iOS)
- **Admin Dashboard**: React.js
- **Backend**: Node.js + Express.js
- **Database**: MongoDB (recommended) / PostgreSQL
- **Payment Gateway**: Razorpay / Paytm / Cashfree
- **APIs**: BBPS for utility bill payments

## Getting Started

### Prerequisites
- Flutter SDK (latest stable)
- Node.js (v16+)
- MongoDB or PostgreSQL
- Android Studio / Xcode for mobile development

### Installation

#### Mobile App
```bash
cd mobile-app
flutter pub get
flutter run
```

#### Admin Dashboard
```bash
cd admin-dashboard
npm install
npm start
```

#### Backend
```bash
cd backend
npm install
npm run dev
```
